# MetaSystem · Консультация

Веб-приложение для продающей консультации фитнес-тренера с лидом + мини-CRM.

**Тексты презентации:** см. `AGENTS.md`. Без метафор в кавычках, без длинных тире, фразы удобно произносить вслух.

**Скрины сервиса** (блок «Маршрут»): положите PNG в `public/screenshots/` по списку в `public/screenshots/README.md`.

## Возможности

- **5 блоков слайдов** (54 экрана): анкета → образ жизни → оценка → маршрут → тарифы
- **Алгоритм**: BMR (Миффлин–Сан Жеор), TDEE, макросы, срок, светофор доменов, флаги, библиотека рекомендаций
- **UX на созвоне**: голосовой ввод (Web Speech API), автосейв, быстрые теги
- **Мини-CRM**: статусы, дата касания, заметки, история, дозаполнение карточки
- **PDF** рекомендаций в дизайн-системе
- **Supabase** (опционально) + localStorage по умолчанию

## Запуск

```bash
cd metasystem
npm install
npm run dev
```

Откройте URL из терминала (обычно http://localhost:5173).

## Supabase (опционально)

1. Создайте проект в Supabase  
2. Выполните SQL из `supabase/schema.sql`  
3. Скопируйте `.env.example` → `.env` и заполните ключи  
4. Перезапустите `npm run dev`

Без `.env` всё работает локально в браузере.
