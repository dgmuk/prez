# Скрины сервиса MetaSystem

Положите PNG/JPG/WebP сюда. Имена файлов фиксированные.

| Файл | Где в консультации | Что снять |
|------|-------------------|-----------|
| `diary-log.png` | Дневник тренировок | Экран записи подхода: вес, повторы, запас сил |
| `diary-timer.png` | Дневник (опционально) | Таймер отдыха / список упражнений |
| `metrics.png` | Как видно, что растёшь | График силы, вес, фото, календарь |
| `cabinet.png` | Всё в одном кабинете | Главный экран кабинета |
| `program.png` | Шаг 3. Программа | Неделя программы / список тренировок |
| `adjust.png` | Шаг 4. Правки | Экран правки / новая версия недели |
| `screening.png` | Шаг 2. Проверка тела | Загрузка видео-тестов |
| `chat.png` | Кабинет / прогресс | Чат с тренером |

Рекомендуемый размер: **1080×1920** (телефон) или **1600×1000** (десктоп).
Тёмный UI, без личных данных клиента.

Если файла нет, на слайде будет аккуратный плейсхолдер с подписью.
